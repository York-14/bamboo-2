# パラメトリック・ケースジェネレーター 要件定義

FDM 3D プリンタで印刷する、スライドフタ付きの角丸ボックス（ケース）を
Web UI 上でパラメータ設計・プレビューし、STL で出力する個人用ツール。

## 0. 前提

| 項目 | 決定 |
|---|---|
| 利用形態 | 自分専用。ローカルで `npm run dev` して使う。対象ブラウザは Chrome のみ |
| 印刷方式 | FDM（ノズル 0.4 mm 想定） |
| 寸法基準 | **内寸** を入力し、外寸は自動計算して表示 |
| フタ | スライド式。初期値は **短辺側から差し込み** |
| ガード用途 | 仕切り・抜け止め |
| 代表サイズ | 内寸 100 × 60 × 30 mm（初期値・テストケース） |
| 単位 | mm 固定 |

## 1. 技術構成

| 役割 | 採用技術 |
|---|---|
| UI | React + TypeScript + Vite |
| 3D プレビュー | Three.js（react-three-fiber + drei） |
| 形状演算 | manifold-3d（WASM）。Web Worker 上で実行 |
| STL 出力 | バイナリ STL を自前で書き出す |
| 保存 | パラメータ JSON の書き出し・読み込み、localStorage への自動保存 |

方針：**パラメータ JSON を唯一の情報源**にし、形状は毎回そこから作り直す。
プレビューと STL は同じメッシュから作るので、必ず一致する。

## 2. 本体

### 2.1 パラメータ

| パラメータ | 記号 | 初期値 |
|---|---|---|
| 内寸 横 | W | 100 |
| 内寸 縦 | D | 60 |
| 内寸 高さ（底面の上側からフタの下面まで） | H | 30 |
| 壁厚 | t_wall | 2.4（溝 1.2 を掘っても 1.2 残る） |
| 底厚 | t_bottom | 2.0 |
| 外側の角の丸み（平面で見た四隅） | R | 4.0 |
| 底面エッジの面取り（任意） | c_bottom | 0 |

### 2.2 計算で決まる値

```
外寸W = W + 2*t_wall
外寸D = D + 2*t_wall
外寸H = t_bottom + H + フタ厚        （フタなしなら t_bottom + H）
内側の角の丸み = max(R - t_wall, 0)
```

## 3. スライドフタ

### 3.1 構造

- フタの上面は本体の上面と揃える（フタの下面 = 底厚 + 内寸高さ）。
- 差し込み側（初期値は短辺側）の壁を、溝の下面（フタ下面 − 厚み方向の隙間）で切り落とす。
- 残りの 3 つの壁の上部内側にフタ用の溝を掘る。
- フタの差し込み側の端には **前リップ** を付け、切り落とした壁を埋めて外形を平らにつなげる。
- 溝とフタの縁の断面は **アリ形**：下から「垂直部分（フタ厚 − 溝の深さ）」＋「45° の斜面（高さ = 溝の深さ）」。
  フタは下面が広く上面が狭いので上には抜けず、差し込み方向にだけスライドする。
  壁側の斜面は内側に張り出す 45° のオーバーハングなので、サポートなしで印刷できる。
- フタは **上下反転して上面をベッドに置いて** 印刷する。斜面は 45° のオーバーハング、クリック凸は上向きになる。
- 隙間は、フタの輪郭を溝より「横方向の隙間」だけ内側にすることで作る（斜面も水平方向に同じだけずらす）。

### 3.2 角の扱い

| モード | 内容 |
|---|---|
| `match`（初期値） | フタの角も丸め、本体の外形に合わせる。フタの平面形状は「内側の角丸長方形を、溝の深さ − 横方向の隙間 だけ外側に広げた形」になり、前リップの外側の角は R に一致する |
| `reduced` | フタ部分だけ角を小さく丸める（`lid.cornerRadius`）。溝の角で壁が薄くなりすぎないか検証する |

補足：平面で見るとフタの外形は凸形状なので、アリ溝やフタの面取り形状は「厚みの異なる 2 段の押し出しの凸包（hull）」で作れる。
溝の差し込み側への逃げは、平行移動したコピーとの凸包で作る。

### 3.3 パラメータ

| パラメータ | 初期値 | 備考 |
|---|---|---|
| フタ厚 | 2.0 | |
| 溝の深さ | 1.2 | 壁厚 ≥ 溝の深さ + 最小壁厚 であることを検証 |
| 横方向の隙間（片側） | 0.25 | |
| 厚み方向の隙間 | 0.2 | |
| 差し込み方向 | 短辺側（−X） | ±X / ±Y から選択 |
| 角のモード | match | match / reduced |
| フタのクリック | 有効、引っかかり 0.4、直径 2.0 | 前リップの下面に球の一部の凸を 2 個、切り落とした壁の上面に一回り大きい凹を作る。凸の高さ = 引っかかり量 + 厚み方向の隙間 |
| 指掛け | 溝 3 本 | なし / 溝 / 円形のくぼみ（ステップ 6） |
| フタの穴 | — | `face = lid` として穴機能を共用する |

### 3.4 嵌合テスト用の小片

同じ壁厚・角の丸み・溝・隙間・クリック設定のまま、内寸を 20 × 30 × 3 mm にした小さなケースとフタを STL で出力する。
本番の印刷前に、隙間とクリックの固さを実物で調整するために使う。

## 4. 壁の穴

- 配置する面：手前（−Y）・奥（+Y）・左（−X）・右（+X）の壁、底面、フタ。
- 位置：
  - 壁は **外から見て** 右方向が u（面の中心から）、v は外形底面からの穴の中心の高さ。
  - 底面・フタは上から見て u = X、v = Y（中心から）。
  - フタの差し込み方向を変えても、壁の穴の位置は変わらない（ワールド座標の面で指定）。
- 形状：円、ティアドロップ（上部を 45° に尖らせ、常に上向き）、長方形、角丸長方形、長穴（両端が半円）、六角形（対辺指定、平らな辺が上下）。
  円・ティアドロップ以外は回転角を指定できる。
- 寸法補正：直径・幅・高さに足す量。初期値 +0.2 mm（印刷設定）。
- 配列：横・縦の個数と間隔。配列全体の中心が指定位置になる。
- 壁の穴は壁だけを貫通させ、内側へは 0.05 mm しか抜かない（壁に接する仕切りの端を削らない）。
- 検証：
  - エラー：面からのはみ出し、寸法が 0 以下、個数が整数でない、フタなしでフタの穴。
  - 警告：壁の角（丸み・隣の壁）にかかる、底面の高さより下、フタの溝の高さにかかる、底面・フタの内側の範囲外、仕切りと重なる（配列は穴ごとに判定）、配列の間隔が穴より狭い。

## 5. ガード

### 5.1 仕切り

| タイプ | 内容 | 主なパラメータ |
|---|---|---|
| 固定仕切り | 本体と一体で印刷する | 方向 X/Y、位置（N 等分 or マイナス側の内壁から板の中心までの距離）、厚み（初期値 1.2）、高さ（「上まで」= フタ下面 − フタとの隙間 1.0、または指定）、指を入れる切り欠き（なし・U字・V字、幅・深さ） |
| 格子仕切り | X 方向と Y 方向を両方有効にする | 方向ごとに等分 or 位置指定。交差部は一体 |
| 着脱式仕切り | 壁に差し込み用の縦溝を作り、仕切り板は別の STL で出力 | 溝の幅、隙間、仕切り板の厚み、切り欠き。交差部は相欠き（互いに半分ずつ切り込みを入れて組む方式） |

実装メモ（ステップ 3）：
- 等分は「区画の内寸」が等しくなるよう、仕切りの厚みを差し引いて配置する。
- 板は壁と底の厚みの中ほどまで食い込ませて一体化し、本体の外形（凸包）で切り取る。
- 切り欠きは、直交する仕切りで区切られた区間ごとに 1 つ、上端の中央に付ける。
- 厚み・高さ・切り欠きは X/Y 共通の設定。方向ごとに変える必要が出たら拡張する。

### 5.2 抜け止め

| タイプ | 用途 | 主なパラメータ |
|---|---|---|
| つぶしリブ | 物を圧入して保持する | 面、位置、本数、高さ、突き出し量（0.3〜0.6） |
| ストッパー（段・爪） | 物の浮き上がり・抜けを防ぐ | 面、位置、幅、突き出し量、下側の斜面角度（初期値 45°） |
| 棚（段差） | 板状の物を載せる | 高さ、奥行き、範囲 |

突起物はすべて下側を 45° 以下の斜面にする（サポート不要）。
突起物は内側の空間で切り取り、外に飛び出さないようにする。
検証：フタのスライド範囲や穴との干渉。

## 6. プレビュー

- 回転・ズーム・パン、視点のプリセット切り替え
- 「組み立てた状態」と「印刷時の配置」の表示切り替え
- フタの開閉スライダー
- 断面表示、フタの半透明表示
- 外寸の表示、警告箇所の色付け表示

## 7. 出力

- STL は部品ごとに出力する：本体 / フタ / 着脱式の仕切り板 / 嵌合テスト用の小片
- 部品は印刷する向きに配置し、Z=0 に接地させる
- 出力するメッシュは manifold（水密）であることを保証する
- パラメータ JSON の保存・読み込み、localStorage への自動保存

## 8. FDM 用の全体設定（初期値）

| 項目 | 値 |
|---|---|
| ノズル径 | 0.4 |
| 最小壁厚 | 1.2 |
| 嵌合の隙間 | 0.2 |
| 穴の寸法補正 | +0.2 |
| オーバーハング上限 | 45° |
| 円弧の分割数 | 64 / 360° |

## 9. 非機能要件

- パラメータ変更からプレビュー更新まで 300 ms 以内（代表サイズ・穴 10 個程度の場合）。入力は間引き（debounce）して処理する。
- 形状計算は Web Worker で行い、UI をブロックしない。

## 10. 開発ステップ

1. 本体（内寸指定・壁厚・底厚・角の丸み）＋プレビュー＋STL 出力
2. スライドフタ（溝・前リップ・隙間・フタのクリック）＋嵌合テスト用の小片
3. 仕切り（固定仕切り・N 等分・切り欠き・格子）
4. 穴（基本形状・ティアドロップ・寸法補正・配列）
5. 抜け止め（つぶしリブ・ストッパー・棚）
6. 着脱式仕切り、フタ開閉アニメーション、指掛け
