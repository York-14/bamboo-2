FDM 3D プリンタ向けパラメトリックケースジェネレーターの最初のリリースです（要件定義のステップ 1〜5）。

## 機能

- **本体**：内寸指定（横・縦・高さ）、壁厚・底厚、角の丸み、底面の面取り。外寸は自動計算
- **スライドフタ**：45° のアリ溝（サポート不要）、前リップ、横・厚み方向の隙間、閉じた位置で留めるクリック、4 方向の差し込み、角の丸みの合わせ方
- **嵌合テスト用の小片**：同じ溝・隙間・クリック設定の小さなケースとフタ
- **仕切り**：等分・位置指定・格子、高さ（フタまで／指定）、U 字・V 字の指掛け切り欠き
- **穴**：壁・底面・フタに、円・ティアドロップ・長方形・角丸長方形・長穴・六角形。回転、寸法補正（+0.2 mm）、配列
- **抜け止め**：つぶしリブ、ストッパー（爪）、棚（壁・全周）。すべて下側 45° 以内でサポート不要
- **プレビュー**：組み立て／印刷配置の切り替え、フタの開閉、断面表示、半透明表示
- **出力**：部品ごとのバイナリ STL（印刷する向きで Z=0 に接地、水密）、パラメータ JSON の保存・読み込み、ブラウザへの自動保存
- **入力チェック**：エラー（形状を更新しない）と警告（印刷前の注意）

## 使い方

- GitHub Pages：<https://york-14.github.io/bamboo-2/>（Pages が有効な場合）
- 手元で：`npm install && npm run dev`
- 添付の zip は静的ファイル一式です。任意の静的 Web サーバーのルートに置いて開いてください（`file://` では Web Worker が動きません）。

## 既知の制限

- 着脱式の仕切り、フタの指掛けは未実装（ステップ 6 の予定）
- 穴・抜け止めの位置は数値入力のみ（プレビュー上でのドラッグ配置は未対応）
- 対象ブラウザは Chrome
